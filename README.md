# ⚡ AI-Powered To-Do Frontend (`ai-todo-fe`)

A sleek, responsive React 19 + Vite web application showcasing smart task management powered by Google Gemini AI.

## ✨ Features

- **Intuitive Task Operations**: Create, filter, search, categorize, and complete tasks with snappy feedback.
- **✨ AI Smart Goal Breakdown**: Enter any ambitious goal or project (e.g. "Prepare for AWS Certification", "Launch MVP") and let Gemini AI automatically break it down into realistic, sequential subtasks with difficulty/priority ratings.
- **🧠 AI Productivity Coach & Prioritizer**: Evaluates active tasks in real-time, spotlights your highest-leverage focus item and fastest quick-win, and dispenses strategic productivity tips.
- **☀️ AI Daily Briefing**: Summarizes daily progress and delivers punchy motivation.
- **Responsive & Modern UI**: Built with a modern dark theme, glassmorphism accents, and accessible interactions.
- **Dual Mode**: Runs effortlessly with either direct Gemini API keys or the backend's intelligent heuristic fallback.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

App will run on `http://localhost:3000` (automatically proxies `/api` calls to the backend on port 5000).
